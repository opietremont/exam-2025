### Exercice 1 : Calcul numérique (4 points)

**1.** Calculs :

**Pour A :**
$$A = \frac{8}{17} - \frac{3}{34} + \frac{5}{51}$$

Dénominateur commun : 102 (car 102 = 6×17 = 3×34 = 2×51)

$$A = \frac{48}{102} - \frac{9}{102} + \frac{10}{102}$$

$$A = \frac{49}{102}$$

(Irréductible car 49 = 7² et 102 = 2×3×17, pas de facteur commun)

**Pour B :**
$$B = \left(\frac{7}{13} - \frac{4}{26}\right) \times \frac{39}{35}$$

$$B = \left(\frac{14}{26} - \frac{4}{26}\right) \times \frac{39}{35}$$

$$B = \frac{10}{26} \times \frac{39}{35}$$

$$B = \frac{5}{13} \times \frac{39}{35}$$ (en simplifiant 10/26 par 2)

$$B = \frac{5 \times 39}{13 \times 35} = \frac{195}{455}$$

Simplifions : GCD(195, 455) = 65

$$B = \frac{3}{7}$$

**Pour C :**
$$C = \frac{\frac{11}{6} - \frac{7}{8}}{\frac{5}{12} + \frac{9}{16}}$$

Numérateur : $\frac{11}{6} - \frac{7}{8} = \frac{44}{24} - \frac{21}{24} = \frac{23}{24}$

Dénominateur : $\frac{5}{12} + \frac{9}{16} = \frac{20}{48} + \frac{27}{48} = \frac{47}{48}$

$$C = \frac{23}{24} \div \frac{47}{48} = \frac{23}{24} \times \frac{48}{47}$$

$$C = \frac{23 \times 48}{24 \times 47} = \frac{23 \times 2}{47} = \frac{46}{47}$$

**2.** Écriture scientifique de D :

$$D = \frac{6,4 \times 10^{-5} \times 4,2 \times 10^{-6}}{3,2 \times 10^{-11}}$$

$$D = \frac{6,4 \times 4,2}{3,2} \times 10^{-5-6-(-11)}$$

### Exercice 3 : Équations et problème (2,5 points)

**1.** Résolution :

$$\frac{4x - 3}{5} - \frac{2x + 7}{3} = \frac{x - 1}{15}$$

Multiplions par 15 (dénominateur commun) :

$$3(4x - 3) - 5(2x + 7) = x - 1$$

$$12x - 9 - 10x - 35 = x - 1$$

$$2x - 44 = x - 1$$

$$2x - x = -1 + 44$$

$$x = 43$$

**2.** Problème du rectangle :

Soit $x$ la largeur du rectangle en cm.

Longueur : $3x + 4$ cm

Périmètre : $2(x + 3x + 4) = 104$

$$2(4x + 4) = 104$$

$$8x + 8 = 104$$

$$8x = 96$$

$$x = 12$$

**Largeur = 12 cm**

**Longueur = 3 × 12 + 4 = 40 cm**

Vérification : $2(12 + 40) = 2 \times 52 = 104$ cm ✓

### Exercice 4 : Théorème de Pythagore (3 points)

**1.** Calcul de EF :

Le triangle DEF est rectangle en E, donc d'après le théorème de Pythagore :

$$DF^2 = DE^2 + EF^2$$

$$130^2 = 78^2 + EF^2$$

$$16900 = 6084 + EF^2$$

$$EF^2 = 10816$$

$$EF = 104 \text{ mm}$$

**2.** Calcul de GH :

EG = 26 mm, donc DG = DE - EG = 78 - 26 = 52 mm

Le triangle DEF est rectangle en E.

Dans ce triangle : $\tan(\widehat{EDF}) = \frac{EF}{DE} = \frac{104}{78} = \frac{4}{3}$

Le triangle DGH est rectangle en G (car (GH) ⊥ (DE)).

Dans ce triangle : $\tan(\widehat{GDH}) = \frac{GH}{DG}$

Or $\widehat{GDH} = \widehat{EDF}$, donc :

$$\frac{GH}{52} = \frac{4}{3}$$

$$GH = 52 \times \frac{4}{3} = \frac{208}{3} \text{ mm} \approx 69,3 \text{ mm}$$

**3.** Aire du triangle DGH :

Le triangle DGH est rectangle en G :

$$\text{Aire} = \frac{DG \times GH}{2} = \frac{52 \times \frac{208}{3}}{2}$$

$$\text{Aire} = \frac{10816}{6} = \frac{5408}{3} \text{ mm}^2 \approx 1802,7 \text{ mm}^2$$

### Exercice 5 : Angles dans un triangle (3,5 points)

**1.** Calcul de $\widehat{ABD}$ :

Dans le triangle ABD rectangle en D, la somme des angles est 180°.

$$\widehat{BAD} + \widehat{ABD} + \widehat{ADB} = 180°$$

$$52° + \widehat{ABD} + 90° = 180°$$

$$\widehat{ABD} = 180° - 52° - 90° = 38°$$

**2.** Calcul de $\widehat{BAC}$ :

Dans le triangle ABC, la somme des angles est 180°.

$$\widehat{BAC} + \widehat{ABC} + \widehat{ACB} = 180°$$

Or $\widehat{ABC} = \widehat{ABD} = 38°$ (car D est sur [BC])

$$\widehat{BAC} + 38° + 68° = 180°$$

$$\widehat{BAC} = 180° - 38° - 68° = 74°$$

**3.** Calcul de $\widehat{CAD}$ :

L'angle $\widehat{BAC}$ est composé de $\widehat{BAD}$ et $\widehat{CAD}$ :

$$\widehat{BAC} = \widehat{BAD} + \widehat{CAD}$$

$$74° = 52° + \widehat{CAD}$$

$$\widehat{CAD} = 74° - 52° = 22°$$

### Exercice 6 : Translation et aires (3,5 points)

**1.** Aire du trapèze ABCD :

$$\text{Aire} = \frac{(AB + CD) \times h}{2}$$

$$\text{Aire} = \frac{(78 + 52) \times 45}{2}$$

$$\text{Aire} = \frac{130 \times 45}{2} = \frac{5850}{2} = 2925 \text{ mm}^2$$

**2.** Nature de ABB'A' :

Une translation conserve les longueurs et le parallélisme.

On a : $\vec{AA'} = \vec{BB'} = \vec{v}$ (définition de la translation)

Donc AA' = BB' et (AA') // (BB').

**Le quadrilatère ABB'A' est un parallélogramme** (côtés opposés parallèles et égaux).

**3.** Périmètre de ABB'A' :

La translation déplace chaque point de 6 cm horizontalement et 4 cm verticalement.

$$AA' = BB' = \sqrt{6^2 + 4^2} = \sqrt{36 + 16} = \sqrt{52} = 2\sqrt{13} \text{ cm}$$

Convertissons : $2\sqrt{13}$ cm = $20\sqrt{13}$ mm

$$\text{Périmètre} = 2 \times AB + 2 \times AA'$$

$$\text{Périmètre} = 2 \times 78 + 2 \times 20\sqrt{13}$$

$$\text{Périmètre} = 156 + 40\sqrt{13} \text{ mm} \approx 156 + 144,2 \approx 300,2 \text{ mm}$$

**4.** Zone commune :

Si la translation déplace le trapèze vers la droite et vers le bas sans chevauchement, **il n'y a pas de zone commune**.

Si les trapèzes se chevauchent, la zone commune serait un quadrilatère dont l'aire dépendrait des positions exactes. Avec les données fournies (translation de 6 cm à droite et 4 cm vers le bas), et sans connaître les dimensions exactes du trapèze, on peut estimer qu'il y a probablement un chevauchement partiel, mais le calcul nécessiterait plus d'informations sur la forme précise du trapèze.

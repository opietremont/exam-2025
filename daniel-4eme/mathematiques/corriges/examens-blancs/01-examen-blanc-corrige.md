### Exercice 1 : Calcul numérique (4 points)

**1.** Calculs :

**Pour A :**
$$A = \frac{5}{7} - \frac{3}{11} \times \frac{22}{9}$$

$$A = \frac{5}{7} - \frac{3 \times 22}{11 \times 9}$$

$$A = \frac{5}{7} - \frac{66}{99}$$

$$A = \frac{5}{7} - \frac{2}{3}$$ (en simplifiant 66/99 par 33)

$$A = \frac{15}{21} - \frac{14}{21}$$ (dénominateur commun : 21)

$$A = \frac{1}{21}$$

**Pour B :**
$$B = \left(\frac{4}{13} + \frac{7}{26}\right) \div \frac{3}{52}$$

$$B = \left(\frac{8}{26} + \frac{7}{26}\right) \div \frac{3}{52}$$

$$B = \frac{15}{26} \times \frac{52}{3}$$

$$B = \frac{15 \times 52}{26 \times 3}$$

$$B = \frac{15 \times 2}{3}$$ (simplification par 26)

$$B = \frac{30}{3} = 10$$

**Pour C :**
$$C = \frac{-\frac{8}{3} + \frac{5}{6}}{\frac{7}{9} - \frac{2}{3}}$$

Numérateur : $-\frac{8}{3} + \frac{5}{6} = -\frac{16}{6} + \frac{5}{6} = -\frac{11}{6}$

Dénominateur : $\frac{7}{9} - \frac{2}{3} = \frac{7}{9} - \frac{6}{9} = \frac{1}{9}$

$$C = -\frac{11}{6} \div \frac{1}{9} = -\frac{11}{6} \times \frac{9}{1} = -\frac{99}{6} = -\frac{33}{2}$$

**2.** Écriture scientifique de D :

### Exercice 2 : Calcul littéral (3,5 points)

**a)** Développement :

$$E = (3x - 7)(2x + 5) - (x - 4)(x + 9)$$

$$E = 6x^2 + 15x - 14x - 35 - (x^2 + 9x - 4x - 36)$$

$$E = 6x^2 + x - 35 - x^2 - 5x + 36$$

$$E = 5x^2 - 4x + 1$$

**b)** Calcul pour x = -3 :

$$E = 5 \times (-3)^2 - 4 \times (-3) + 1$$

$$E = 5 \times 9 + 12 + 1$$

$$E = 45 + 12 + 1 = 58$$

**c)** Factorisations :

**Pour F :**
$$F = (2x + 7)(5x - 3) + (2x + 7)(x + 8)$$

Facteur commun : $(2x + 7)$

$$F = (2x + 7)[(5x - 3) + (x + 8)]$$

$$F = (2x + 7)(6x + 5)$$

**Pour G :**
$$G = 16x^2 - 49$$

Identité remarquable : $a^2 - b^2 = (a-b)(a+b)$ avec $a = 4x$ et $b = 7$

$$G = (4x)^2 - 7^2$$

$$G = (4x - 7)(4x + 7)$$

### Exercice 3 : Équations (2,5 points)

**a)** Résolution :

$$5(x - 3) - 2(3x + 7) = 4x - 11$$

$$5x - 15 - 6x - 14 = 4x - 11$$

$$-x - 29 = 4x - 11$$

$$-x - 4x = -11 + 29$$

$$-5x = 18$$

$$x = -\frac{18}{5}$$

**b)** Résolution :

$$\frac{2x - 1}{3} - \frac{x + 5}{4} = \frac{1}{6}$$

Dénominateur commun : 12

## GÉOMÉTRIE (10 points)

### Exercice 4 : Théorème de Pythagore (3 points)

**1.** Calcul de AC :

Le triangle ABC est rectangle en A, donc d'après le théorème de Pythagore :

$$BC^2 = AB^2 + AC^2$$

$$91^2 = 84^2 + AC^2$$

$$8281 = 7056 + AC^2$$

$$AC^2 = 8281 - 7056 = 1225$$

$$AC = \sqrt{1225} = 35 \text{ mm}$$

**2.** Calcul de BE :

DB = AB - AD = 84 - 36 = 48 mm

Le triangle BDE est rectangle en D (car DE ⊥ AB).

Dans le triangle ABC rectangle en A : $\tan(\widehat{ABC}) = \frac{AC}{AB} = \frac{35}{84} = \frac{5}{12}$

Dans le triangle BDE rectangle en D : $\tan(\widehat{DBE}) = \frac{DE}{DB}$

Or $\widehat{DBE} = \widehat{ABC}$, donc $\frac{DE}{48} = \frac{5}{12}$

Donc $DE = \frac{48 \times 5}{12} = 20$ mm

D'après le théorème de Pythagore dans BDE :

$$BE^2 = BD^2 + DE^2 = 48^2 + 20^2 = 2304 + 400 = 2704$$

$$BE = \sqrt{2704} = 52 \text{ mm}$$

**3.** Le triangle BDE est-il rectangle ?

Nous avons déjà établi que le triangle BDE est rectangle en D (car DE ⊥ AB par construction).

### Exercice 5 : Volumes (3,5 points)

**1.** Volume du cylindre :

La formule du volume d'un cylindre de révolution est :

$$V = \pi r^2 h$$

Avec $r = 42$ mm et $h = 91$ mm :

$$V_{cylindre} = \pi \times 42^2 \times 91$$

$$V_{cylindre} = \pi \times 1764 \times 91$$

$$V_{cylindre} = 160524\pi \text{ mm}^3$$

**Valeur arrondie** : $V_{cylindre} \approx 504206 \text{ mm}^3$

**2.** Volume du cône :

La formule du volume d'un cône de révolution est :

$$V = \frac{1}{3}\pi r^2 h$$

Avec la même base et la même hauteur que le cylindre :

$$V_{cône} = \frac{1}{3} \times \pi \times 42^2 \times 91$$

$$V_{cône} = \frac{160524\pi}{3} = 53508\pi \text{ mm}^3$$

**Valeur arrondie** : $V_{cône} \approx 168069 \text{ mm}^3$

**3.** Pourcentage :

$$\frac{V_{cône}}{V_{cylindre}} = \frac{53508\pi}{160524\pi} = \frac{53508}{160524} = \frac{1}{3}$$

**Le volume du cône représente exactement $\frac{1}{3}$ du volume du cylindre, soit environ 33,33 %.**

### Exercice 6 : Aires et transformations (3,5 points)

**1.** Nature de EFGH :

E, F, G, H sont les milieux des côtés du carré ABCD.

Le quadrilatère formé par les milieux des côtés d'un carré est un carré.

On peut le démontrer : EF, FG, GH et HE ont tous la même longueur (par symétrie), et les angles sont droits.

Calcul : $EF = \sqrt{AE^2 + AF^2} = \sqrt{24^2 + 24^2} = 24\sqrt{2}$ mm

**Donc EFGH est un carré.**

**2.** Aire du carré ABCD :

$$\text{Aire}_{ABCD} = 48^2 = 2304 \text{ mm}^2$$

**3.** Aire de EFGH :

$$\text{Aire}_{EFGH} = (24\sqrt{2})^2 = 576 \times 2 = 1152 \text{ mm}^2$$

Ou bien : Aire de EFGH = $\frac{1}{2}$ Aire de ABCD = $\frac{2304}{2} = 1152$ mm²

**4.** Symétrie centrale :

Dans une symétrie centrale de centre O, le point A est transformé en A' tel que O est le milieu de [AA'].

Donc $AA' = 2 \times AO$.

AO est la demi-diagonale du carré : $AO = \frac{48\sqrt{2}}{2} = 24\sqrt{2}$ mm

Donc $AA' = 2 \times 24\sqrt{2} = 48\sqrt{2}$ mm $\approx 67,9$ mm

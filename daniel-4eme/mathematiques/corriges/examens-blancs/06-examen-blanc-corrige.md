### Exercice 1 : Calcul numérique (3,5 points)

**1.** Calculs :

**Pour A :**
$$A = \frac{11}{26} + \frac{5}{39} - \frac{7}{52}$$

Dénominateur commun : 156 (car 156 = 6×26 = 4×39 = 3×52)

$$A = \frac{66}{156} + \frac{20}{156} - \frac{21}{156}$$

$$A = \frac{65}{156}$$

Simplifions : GCD(65, 156) = 13

$$A = \frac{5}{12}$$

**Pour B :**
$$B = \left(\frac{9}{17} + \frac{2}{51}\right) : \frac{13}{34}$$

$$B = \left(\frac{27}{51} + \frac{2}{51}\right) \times \frac{34}{13}$$

$$B = \frac{29}{51} \times \frac{34}{13}$$

$$B = \frac{29 \times 34}{51 \times 13} = \frac{986}{663}$$

Simplifions : 51 = 3×17 et 663 = 51×13, et 986 = 29×34 = 29×2×17

GCD(986, 663) = 17

$$B = \frac{58}{39}$$

**2.** Puissance de 5 :

$$C = \frac{5^7 \times (5^{-2})^3}{5^{-4} \times 5^5}$$

$$C = \frac{5^7 \times 5^{-6}}{5^{-4} \times 5^5}$$

$$C = \frac{5^{7-6}}{5^{-4+5}}$$

$$C = \frac{5^1}{5^1} = 5^0 = 1$$

Ou bien : $C = 5^{7-6-(-4)-5} = 5^{7-6+4-5} = 5^0 = 1$

**3.** Notation scientifique :

$$D = \frac{8,1 \times 10^{-7} \times 1,6 \times (10^4)^2}{2,7 \times 10^{-3}}$$

$$D = \frac{8,1 \times 10^{-7} \times 1,6 \times 10^8}{2,7 \times 10^{-3}}$$

$$D = \frac{8,1 \times 1,6}{2,7} \times 10^{-7+8-(-3)}$$

$$D = \frac{12,96}{2,7} \times 10^{4}$$

$$D = 4,8 \times 10^{4}$$

### Exercice 2 : Calcul littéral (4 points)

**a)** Développement :

$$E = (6x - 5)^2 - (2x + 3)(4x - 7)$$

$$E = 36x^2 - 60x + 25 - (8x^2 - 14x + 12x - 21)$$

$$E = 36x^2 - 60x + 25 - 8x^2 + 14x - 12x + 21$$

$$E = 28x^2 - 58x + 46$$

**b)** Factorisations :

**Pour F :**
$$F = (5x + 8)(3x - 4) + (3x - 4)(2x - 9)$$

Facteur commun : $(3x - 4)$

$$F = (3x - 4)[(5x + 8) + (2x - 9)]$$

$$F = (3x - 4)(7x - 1)$$

**Pour G :**
$$G = 64x^2 - 25$$

Identité remarquable : $a^2 - b^2 = (a-b)(a+b)$

$$G = (8x)^2 - 5^2$$

$$G = (8x - 5)(8x + 5)$$

**Pour H :**
$$H = 16x^2 + 56x + 49$$

Identité remarquable : $a^2 + 2ab + b^2 = (a+b)^2$

$$H = (4x)^2 + 2 \times 4x \times 7 + 7^2$$

$$H = (4x + 7)^2$$

**c)** Factorisation de K par deux méthodes :

$$K = (3x - 7)^2 - 36$$

**Méthode 1 : Identité remarquable $a^2 - b^2$**

$$K = (3x - 7)^2 - 6^2$$

$$K = [(3x - 7) - 6][(3x - 7) + 6]$$

$$K = (3x - 13)(3x - 1)$$

**Méthode 2 : Développement puis factorisation**

$$K = 9x^2 - 42x + 49 - 36$$

$$K = 9x^2 - 42x + 13$$

On cherche deux nombres dont le produit est $9 \times 13 = 117$ et la somme est $-42$.
Ces nombres sont $-39$ et $-3$.

$$K = 9x^2 - 39x - 3x + 13$$

$$K = 3x(3x - 13) - 1(3x - 13)$$

$$K = (3x - 13)(3x - 1)$$

### Exercice 3 : Problème de proportionnalité (2,5 points)

**a)** Surface avec 17 kg :

Si 26 kg permettent de fertiliser 312 m², alors 17 kg permettent de fertiliser :

$$\text{Surface} = \frac{312 \times 17}{26} = \frac{5304}{26} = 204 \text{ m}^2$$

**b)** Quantité pour 540 m² :

$$\text{Quantité} = \frac{540 \times 26}{312} = \frac{14040}{312} = 45 \text{ kg}$$

**c)** Coût total :

$$\text{Coût} = 45 \times 3,70 = 166,50 \text{ €}$$

### Exercice 4 : Théorème de Pythagore (3 points)

**1.** Le triangle est-il rectangle ?

Calculons et comparons les carrés des longueurs :

$$QR^2 = 144^2 = 20736$$
$$RS^2 = 108^2 = 11664$$
$$QS^2 = 180^2 = 32400$$

Vérifions : $QR^2 + RS^2 = 20736 + 11664 = 32400 = QS^2$

D'après la réciproque du théorème de Pythagore, **le triangle QRS est rectangle en R.**

**2.** Aire du triangle QRS :

Le triangle QRS est rectangle en R, donc :

$$\text{Aire} = \frac{QR \times RS}{2} = \frac{144 \times 108}{2} = \frac{15552}{2} = 7776 \text{ mm}^2$$

**3.** Aire du triangle RST :

RT = 48 mm, donc QT = QR - RT = 144 - 48 = 96 mm.

Les triangles RST et RSQ ont le même sommet S et leurs bases sont sur la droite (QR).

Le rapport des aires est égal au rapport des bases :

$$\frac{\text{Aire}_{RST}}{\text{Aire}_{RSQ}} = \frac{RT}{RQ} = \frac{48}{144} = \frac{1}{3}$$

$$\text{Aire}_{RST} = \frac{7776}{3} = 2592 \text{ mm}^2$$

### Exercice 5 : Échelle et agrandissement (3,5 points)

**1.** Distance réelle entre A et B :

Échelle : $\frac{1}{250000}$ signifie que 1 cm sur la carte représente 250 000 cm dans la réalité.

Distance sur la carte : 6,3 cm

Distance réelle : $6,3 \times 250000 = 1575000$ cm

Conversion en km : $1575000$ cm $= 15750$ m $= 15,75$ km

**La distance réelle entre A et B est 15,75 km ou 15 km 750 m.**

**2.** Distance sur la carte entre C et D :

Distance réelle : 108 km = 10800000 cm

$$\text{Distance sur la carte} = \frac{10800000}{250000} = 43,2 \text{ cm}$$

**La distance sur la carte entre C et D est 43,2 cm.**

**3.** Nouvelle échelle après agrandissement :

Rapport d'agrandissement : 1,44

Les distances sur la carte sont multipliées par 1,44.

Donc l'échelle est divisée par 1,44 :

$$\text{Nouvelle échelle} = \frac{1}{250000 / 1,44} = \frac{1,44}{250000} = \frac{1}{173611}$$

Arrondissons : $\frac{1}{173600}$ ou environ $\frac{1}{174000}$

**La nouvelle échelle est environ $\frac{1}{173600}$.**

### Exercice 6 : Transformations géométriques (3,5 points)

**1.** Rotation :

**a)** Une rotation conserve les longueurs.

$$BA' = BA = 6,4 \text{ cm}$$

$$BC' = BC = 7,8 \text{ cm}$$

**b)** Par définition de la rotation :

$$\widehat{ABA'} = 90°$$

**2.** Symétrie axiale :

**a)** Une symétrie axiale conserve les longueurs.

$$A''B = AB = 6,4 \text{ cm}$$

**b)** Dans une symétrie d'axe (BC) :
- B est sur l'axe, donc B est invariant
- C est sur l'axe, donc C est invariant
- A'' est le symétrique de A par rapport à (BC)

Le quadrilatère ABA''C a :
- BC comme axe de symétrie
- BA = BA'' (par symétrie)

**ABA''C est un cerf-volant** (quadrilatère ayant un axe de symétrie passant par deux sommets opposés).

**3.** Périmètre du triangle ABC :

$$\text{Périmètre} = AB + BC + AC$$

$$\text{Périmètre} = 6,4 + 7,8 + 5,2 = 19,4 \text{ cm}$$

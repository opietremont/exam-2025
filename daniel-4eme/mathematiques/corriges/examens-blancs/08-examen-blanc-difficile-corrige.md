### Exercice 2 : Calcul littéral (3 points)

**a)** Développement :

$$E = (4x + 3)^2 - (5x - 2)(3x + 7) + (2x - 1)^2$$

$$E = 16x^2 + 24x + 9 - (15x^2 + 35x - 6x - 14) + 4x^2 - 4x + 1$$

$$E = 16x^2 + 24x + 9 - 15x^2 - 29x + 14 + 4x^2 - 4x + 1$$

$$E = 5x^2 - 9x + 24$$

**b)** Factorisations :

**Pour F :**
$$F = (3x + 8)(7x - 5) + (7x - 5)(2x - 9)$$

Facteur commun : $(7x - 5)$

$$F = (7x - 5)[(3x + 8) + (2x - 9)]$$

$$F = (7x - 5)(5x - 1)$$

**Pour G :**
$$G = (6x - 7)^2 - 81$$

Identité remarquable : $a^2 - b^2 = (a-b)(a+b)$

$$G = (6x - 7)^2 - 9^2$$

$$G = [(6x - 7) - 9][(6x - 7) + 9]$$

$$G = (6x - 16)(6x + 2)$$

$$G = 2(3x - 8) \times 2(3x + 1)$$

$$G = 4(3x - 8)(3x + 1)$$

**Pour H :**
$$H = 4x^2 - 36x + 81$$

Identité remarquable : $a^2 - 2ab + b^2 = (a-b)^2$

$$H = (2x)^2 - 2 \times 2x \times 9 + 9^2$$

$$H = (2x - 9)^2$$

**c)** Factorisation et calcul de K :

$$K = 16x^2 - 24xy + 9y^2$$

Identité remarquable : $a^2 - 2ab + b^2 = (a-b)^2$

$$K = (4x)^2 - 2 \times 4x \times 3y + (3y)^2$$

$$K = (4x - 3y)^2$$

Pour $x = \frac{5}{8}$ et $y = \frac{2}{3}$ :

$$K = \left(4 \times \frac{5}{8} - 3 \times \frac{2}{3}\right)^2$$

$$K = \left(\frac{20}{8} - \frac{6}{3}\right)^2$$

$$K = \left(\frac{5}{2} - 2\right)^2$$

$$K = \left(\frac{1}{2}\right)^2 = \frac{1}{4}$$

### Exercice 3 : Système d'équations à deux inconnues (3 points)

**1.** Mise en équation :

Soit $x$ le nombre de romans vendus et $y$ le nombre de bandes dessinées vendues.

- Il y a 156 livres vendus au total : $x + y = 156$
- Un roman coûte 5 €, une BD coûte 3 €, total 624 € : $5x + 3y = 624$

**Système :**

$$\begin{cases}
x + y = 156 \\
5x + 3y = 624
\end{cases}$$

**2.** Résolution :

De l'équation (1) : $y = 156 - x$

Substituons dans l'équation (2) :

$$5x + 3(156 - x) = 624$$

$$5x + 468 - 3x = 624$$

$$2x = 624 - 468$$

$$2x = 156$$

$$x = 78$$

Donc : $y = 156 - 78 = 78$

**Vérification :**
- Nombre total de livres : $78 + 78 = 156$ ✓
- Montant total : $5 \times 78 + 3 \times 78 = 390 + 234 = 624$ € ✓

**Réponse : Il y a eu 78 romans et 78 bandes dessinées vendus.**

## GÉOMÉTRIE (10 points)

### Exercice 4 : Théorème de Pythagore (3,5 points)

**1.** Calcul de EG :

EFGH est un rectangle, donc le triangle EFG est rectangle en F.

D'après le théorème de Pythagore :

$$EG^2 = EF^2 + FG^2$$

$$EG^2 = 126^2 + 168^2$$

$$EG^2 = 15876 + 28224 = 44100$$

$$EG = 210 \text{ mm}$$

**2.** Calcul de KL :

Si (KL) est perpendiculaire à (EF), et que EFGH est un rectangle, alors (KL) est parallèle à (FG).

Donc $KL = FG = 168$ mm.

**3.** Alignement de E, K, G :

Les points E, K et L ne sont pas alignés avec G car K est sur [EF] et L est sur [GH], qui sont des côtés opposés du rectangle. Pour qu'ils soient alignés, il faudrait une configuration particulière qui n'est pas le cas ici.

**4.** Aire du triangle EKL :

Le triangle EKL a pour base EK = 54 mm et pour hauteur la distance de L à la droite (EF), qui est égale à FG = 168 mm.

$$\text{Aire} = \frac{EK \times FG}{2} = \frac{54 \times 168}{2} = \frac{9072}{2} = 4536 \text{ mm}^2$$

### Exercice 5 : Probabilités (3,5 points)

**1.** Probabilité de tirer une bille rouge :

Nombre de billes rouges : 8

Nombre total de billes : 26

$$P(\text{rouge}) = \frac{8}{26} = \frac{4}{13}$$

**2.** Probabilité de tirer une bille qui n'est pas verte :

Nombre de billes non vertes : 8 (rouges) + 11 (bleues) = 19

$$P(\text{non verte}) = \frac{19}{26}$$

**3.** Probabilité de tirer deux billes rouges (tirages successifs sans remise) :

Probabilité de tirer une rouge au 1er tirage : $\frac{8}{26}$

Après avoir tiré une rouge, il reste 7 rouges sur 25 billes.

Probabilité de tirer une rouge au 2ème tirage sachant qu'on a tiré une rouge au 1er : $\frac{7}{25}$

$$P(\text{deux rouges}) = \frac{8}{26} \times \frac{7}{25} = \frac{56}{650}$$

Simplifions : $\frac{56}{650} = \frac{28}{325}$

**La probabilité de tirer deux billes rouges est $\frac{28}{325}$.**

### Exercice 6 : Aires et proportionnalité (3 points)

**1.** Le triangle est-il rectangle ?

Calculons et comparons les carrés des longueurs :

$$MN^2 = 84^2 = 7056$$
$$NP^2 = 112^2 = 12544$$
$$MP^2 = 140^2 = 19600$$

Vérifions : $MN^2 + NP^2 = 7056 + 12544 = 19600 = MP^2$

D'après la réciproque du théorème de Pythagore, **le triangle MNP est rectangle en N.**

**2.** Calcul de QR :

La droite (QR) est parallèle à (NP), donc par le théorème de Thalès dans le triangle MNP :

$$\frac{MQ}{MN} = \frac{MR}{MP} = \frac{QR}{NP}$$

$$\frac{QR}{NP} = \frac{MQ}{MN} = \frac{36}{84} = \frac{3}{7}$$

$$QR = NP \times \frac{3}{7} = 112 \times \frac{3}{7} = \frac{336}{7} = 48 \text{ mm}$$

**3.** Calcul de MR :

$$\frac{MR}{MP} = \frac{3}{7}$$

$$MR = MP \times \frac{3}{7} = 140 \times \frac{3}{7} = \frac{420}{7} = 60 \text{ mm}$$

**4.** Rapport des aires :

Le rapport des côtés entre les triangles MQR et MNP est $k = \frac{3}{7}$.

Le rapport des aires est $k^2 = \left(\frac{3}{7}\right)^2 = \frac{9}{49}$.

$$\frac{\text{Aire}(MQR)}{\text{Aire}(MNP)} = \frac{9}{49}$$

# Autonomy Rule

- **Proceed without asking** when subject, topic, and difficulty are all specified.
- **Ask first** when the request is ambiguous (missing topic or difficulty level).
- **Flag and stop** if a requested notion is outside the 3ème programme — suggest the closest in-scope alternative.
- The operator can override any rule explicitly at any time.

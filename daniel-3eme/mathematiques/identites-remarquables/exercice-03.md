# Exercice — Identités remarquables (Feuille 3 — expert)

**Matière** : Mathématiques — 3ème
**Chapitre** : Calcul littéral — identités remarquables
**Date** : 2026-10-04

**Notions** : (a + b)² ; (a − b)² ; (a + b)(a − b) = a² − b² ; expressions à trois lettres ; regroupements ; factorisation complète ; équation produit nul ; calcul sur les entiers ; théorème de Pythagore ; signe d'un carré ; démonstration.

---

## Énoncé

### A. Développer sans s'épuiser

1. Développer et réduire, en regroupant les termes deux par deux avant tout calcul :
   A = (a + b + c)² − (a + b − c)² − (a − b + c)² + (a − b − c)²

2. a) Développer astucieusement (x² + 2x + 2)(x² − 2x + 2).
   b) En déduire, sans calculatrice, une écriture de 629 comme produit de deux entiers supérieurs à 1.
   c) Démontrer que, pour tout entier n ≥ 2, le nombre n⁴ + 4 n'est pas un nombre premier.

### B. Factoriser complètement

3. Factoriser complètement : B = (x² + 4)² − 16x².

4. Factoriser : C = x² − y² − 6x + 9.

5. Factoriser complètement, en un produit de quatre facteurs du premier degré :
   D = 4a²b² − (a² + b² − c²)²

### C. Nombres et raisonnement

6. Deux nombres x et y vérifient : x + y = 5 et x² + y² = 13.
   a) Calculer xy.
   b) Calculer (x − y)², puis déterminer les valeurs possibles de x − y.
   c) En déduire toutes les valeurs possibles du couple (x ; y).
   d) Calculer 1/x + 1/y.

7. a) Calculer S = 100² − 99² + 98² − 97² + … + 4² − 3² + 2² − 1².
      *(Donnée : 1 + 2 + 3 + … + 100 = 5 050.)*
   b) Déterminer tous les couples d'entiers naturels (x ; y) tels que x² − y² = 15.

### D. Équations

8. Résoudre les équations suivantes :
   a) (x² − 1)² = (x + 1)²
   b) x² + 6x = 16, en faisant apparaître une identité remarquable.

### E. Démonstrations

9. Soit n un entier supérieur ou égal à 1. Un triangle a pour côtés 2n + 1, 2n² + 2n et 2n² + 2n + 1.
   a) Démontrer que ce triangle est rectangle.
   b) Donner les longueurs des côtés obtenues pour n = 3.

10. a) Démontrer que, pour tous nombres a et b : (a + b)² − 4ab = (a − b)².
    b) En déduire que, pour tous nombres a et b : 4ab ≤ (a + b)².
    c) Un rectangle a un périmètre de 20 cm. Démontrer que son aire est inférieure ou égale à 25 cm², et préciser dans quel cas elle vaut exactement 25 cm².

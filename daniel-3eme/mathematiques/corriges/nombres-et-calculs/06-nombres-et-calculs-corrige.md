**7.** On sait que a + b = 1 et ab = −1. Comme ab ≠ 0, ni a ni b n'est nul.

a) a² + b² = (a + b)² − 2ab = 1 − 2 × (−1) = 1 + 2.
**a² + b² = 3**

b) (a − b)² = a² + b² − 2ab = 3 + 2.
**(a − b)² = 5**, donc **a − b = √5 ou a − b = −√5**.

c) 1/a + 1/b = (a + b)/(ab) = 1/(−1) = **−1**
a/b + b/a = (a² + b²)/(ab) = 3/(−1) = **−3**

d) a⁴ + b⁴ = (a² + b²)² − 2(ab)² = 9 − 2 × 1.
**a⁴ + b⁴ = 7**

*Vérification* : avec a + b = 1 et a − b = √5, on trouve a = (1 + √5)/2 ≈ 1,618 et b = (1 − √5)/2 ≈ −0,618. Alors ab ≈ −1,000 ✓ ; a² + b² ≈ 2,618 + 0,382 = 3 ✓ ; a⁴ + b⁴ ≈ 6,854 + 0,146 = 7 ✓
